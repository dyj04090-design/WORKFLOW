Wordflow 규칙

단어와 예문

  • 추가를 요청한 단어·표현만 등록하고, 중복은 확인합니다.
  • 발음기호, 한국어 뜻, 영어 예문 5개와 각각의 한국어 해석을 넣습니다.
  • 원어민이 실생활에서 흔히 쓰는 상황·말투·단어 조합을 최대한 살려 예문 5개를 만듭니다. 딱딱한 교과서식 문장이나 억지 상황은 피하고, 격식 있는 단어는 실제 쓰이는 격식에 맞춥니다.
  • 메모에는 핵심 뉘앙스, 자주 쓰는 표현, 주의점과 비슷한 표현의 차이를 설명합니다.

이미지

  • 실제 사진을 활용할 수 있으며, 사용자가 직접 요청하거나 GPT가 학습 효과가 더 좋다고 판단하면 AI 이미지를 생성할 수 있습니다. 추상적 표현이나 상황 묘사에 특히 유용합니다.
  • 불필요한 생성을 남발하지 않습니다. 생성 이미지를 단어장에 넣을 때는 임시 링크가 아닌 장기 보관 가능한 유효한 이미지 URL을 확인한 뒤 저장합니다.
  • 기본 1장, 뚜렷하게 다른 뜻을 함께 배우면 2장, 필요한 경우 최대 3장을 사용합니다.
  • 이미지 아래에는 한국어 장면 설명을 표시하고, 복습 중에는 정답 공개 후 보여줍니다.

복습과 데이터 보호

  • 단어 내용 수정 시 기존 복습 기록과 다음 복습 일정은 보존합니다.
  • 로그인 후 서버의 최신 데이터를 불러오고 변경한 항목만 저장합니다. 오래된 기기 데이터의 전체 덮어쓰기를 막습니다.
  • 복습 결과는 그때그때 저장하되, 일반 저장 알림은 띄우지 않습니다. 실패·충돌은 알립니다.
  • JSON 내보내기는 현재 불러온 단어·문장·복습 기록과 진도를 포함합니다. ‘없는 카드 추가’는 전체 복습 기록 복원 기능이 아닙니다.

유지보수

내용 변경 후에는 실제 저장 결과를 확인합니다. 앱 기능 변경 시 버전과 패치노트를 함께 갱신합니다. 규칙을 수정할 때 이 요약도 함께 맞춥니다.
